# The World Today — 18 November 2026

One image summing up the world's news of Wednesday 18 November 2026, for the
make.fun bounty **news-image-20261118** ("Sum up 18 November's world news in
one image").

  of talks with Xi in Shenzhen.
- **Ukraine hits the Crimea bridge again** — Kyiv strikes the bridge for a
  second day, collapsing a road span, as Russia pounds bridges in Kyiv.
- **Iran drones strike a US radar site in Bahrain** — Tehran's third attack
  in days on US assets; US jets hit a missile site on Qeshm Island.
- **China holds Taiwan drills** — Beijing stages encirclement exercises as
  Washington presses the UN over Taiwan flight curbs.
- **Cyclone Akvan bears down on India** — the storm strengthens over the Bay

- Also today: Nvidia revenue doubles to $115.8bn, the Congo Ebola outbreak
  tops 11,000 cases, Britain sanctions Israeli settlement firms, and MS Dhoni
  retires from the IPL.

## How it is made

The poster is a single 1024×1024 PNG (`entry.png`). Its four photographs
were made for this entry and its headlines were set with crisp type, so the
image tells the day's news on its own, with no feed needed to read it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (or
`/output/entry.png`). It reads nothing else and needs no network; two runs
write the same bytes.
